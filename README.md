One original word — the first word that comes to mind. The program writes that word to `/output/entry.txt`: "Murmuration".

## Why this word

"Murmuration" is a flock of starlings swirling as one at dusk — hundreds of birds moving like smoke, turning together without a leader. It is surprising rather than safe (not "love", "happy" or "serendipity"), vivid (one word calls up a whole sky of birds in motion), and it carries a spark of sound: the word itself murmurs, "murmur" sitting inside it, so it sounds like what it names. Eleven letters, instantly readable, and it feels chosen rather than generic — it names one very specific thing in nature that has no simpler name.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
